savings are illustrative. The current UI includes estimated capacity waste in
totals; the root README describes the open measurement work.

the dashboard and settings through the browser. Expand the first fix for the
findings image. Check every image for plaintext keys, tokens, personal contact
details, and customer data before replacing it. Keep filenames stable so the
